# 스타랩코딩학원 광진점 사이트 (starlabcoding.co.kr)

깃허브 페이지로 띄우는 정적 사이트. 저장소 맨 위가 실제 사이트이고, `_src/`는 원본이다.
`_src`처럼 밑줄로 시작하는 폴더는 깃허브 페이지가 공개하지 않는다.

## 고치는 법
1. 첫 페이지 내용·디자인은 `_src/body.html`을 고친다.
2. 글은 `_src/posts_src/`에 파일 하나씩 둔다. 맨 위 `slug: / title: / date: / category: / summary: / source: / answer:` 다음 줄에 `---`, 그 아래 본문 HTML.
   - 블로그 글을 그대로 복사하지 않는다. 네이버 유사문서로 블로그가 빠질 수 있으니 다시 쓴 정리본만 올린다.
   - 블로그 글 하나 = 사이트 글 하나. 여러 글을 합치지 않는다 (source 원문 링크가 하나씩 맞아야 한다).
   - 원문에 없는 내용은 넣지 않는다. 학생 이름·학교는 모두 뺀다.
   - category는 `학부모 질문`, `수업 엿보기`, `대회·자격증` 중 하나.
   - 개강·특강·설명회·교습비 공지, 옛 커리큘럼 안내, 영상만 있는 글, NYPC 글은 옮기지 않는다 (2026-10-01 기준 70편 중 35편 옮김).
3. 사진은 맨 위 `img/`에 넣는다.
4. `_src` 안에서 `python3 build.py`를 실행하면 맨 위 `index.html`, `posts/`, `robots.txt`, `sitemap.xml`, `CNAME`이 다시 만들어진다.
5. 커밋하고 올리면 몇 분 안에 사이트에 반영된다.
